# TEKMANTRIX website
Static site (HTML, CSS, JS). No build step.
**GitHub Pages:** push these files to a repo, then Settings > Pages > deploy from the main branch, root folder.
**Other hosts:** upload the folder contents to any static web host.
Edit text in `index.html`, colours in `:root` of `styles.css`.
The contact form opens the visitor's email app (mailto). For a hosted form, swap in a service such as Formspree.
